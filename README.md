# Imperia Sensa Park - Authentication UI (Next.js + TypeScript)

Dự án tái hiện giao diện Form Đăng nhập & Đăng ký (Sign In / Sign Up) chuẩn theo thiết kế [Imperia Sensa Park.html](file:///Users/gokudev/Desktop/bai-tap-dev-010-va-011/Imperia%20Sensa%20Park.html).

## Công nghệ sử dụng
- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (Icons)

## Hướng dẫn chạy dự án

### 1. Di chuyển vào thư mục dự án
```bash
cd project
```

### 2. Khởi chạy môi trường phát triển (Dev server)
```bash
npm run dev
```
Truy cập [http://localhost:3000](http://localhost:3000) trên trình duyệt.

### 3. Build sản phẩm hoàn chỉnh
```bash
npm run build
npm start
```
